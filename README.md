# Архив 81 · SudokuHelper

Судоку-приключение: восстанови повреждённый архив и узнай, кто отправил тебе предупреждение из будущего. Русский интерфейс, без регистрации, сборки и внешних библиотек.

## Что есть в версии 1.0

- **История:** законченная первая глава «Первый сигнал» на шесть уровней. Четыре обычных судоку, задание на один доказанный ход, поиск подменённой цифры, финал и журнал записей. Все позиции имеют единственное решение; полные уровни первой главы решаются единственными кандидатами. Главы II–V пока обозначены как будущий контент, а не выданы за готовые.
- **Прогресс:** последовательное открытие уровней, три звезды, ранги, опыт, четыре цветовые темы и подтверждение освоения приёма. 100 XP за первое прохождение каждого уровня, 150 XP за завершение главы; максимум первой главы — 750 XP. Повторное прохождение улучшает звёзды без повторной выдачи опыта.
- **Практика:** случайные уникальные сетки, стартовая плотность и отдельная оценка по логическим приёмам. Оценка может отличаться от выбранной сложности генерации.
- **Помощник:** импорт 81 клетки, проверка конфликтов/разрешимости/единственности, копирование, объясняющие подсказки, пошаговое и анимированное решение. При нескольких решениях поиск показывает одно допустимое продолжение.
- **Удобство:** заметки, автоматические кандидаты, отмена до 30 ходов, клавиатура, адаптивная доска, сохранение отдельной партии для каждого режима, экспорт/импорт прогресса и подтверждение сброса. Все данные остаются на устройстве.

Звёзды: одна за прохождение, ещё одна без ошибок, ещё одна без подсказок. Для открытия следующего уровня достаточно одной. Заметки, кандидаты и отмена бесплатны. Авторазбор помечает **всю попытку** как демонстрационную: остановка, отмена и перезагрузка не возвращают право на награду; нужно начать заново. Мастерство засчитывается только за специальное задание без ошибок и подсказок, не за случайный правильный ввод.

## Запуск

Открой `index.html` или размести содержимое репозитория на статическом хостинге. Для предсказуемого сохранения рекомендуется HTTP(S), а не `file:`:

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

В GitHub Pages достаточно публиковать корень `main`, если Pages настроен владельцем. Конфигурация хостинга этим обновлением не меняется. Загрузка шрифтов, CDN, API и аккаунт не нужны.

`localStorage` использует ключ `sudokuhelper.archive81.v1`. Сохранение локальное, без синхронизации между устройствами. Политики браузера, приватный режим или переполненное хранилище могут мешать записи: приложение показывает предупреждение, а игра и экспорт остаются доступны. При повреждённом сохранении автоматическая перезапись отключена до явного импорта/сброса. Перед очисткой браузера экспортируй JSON в профиле. Импорт ограничен 2 МБ и проверяется до замены данных.

## Управление

Цифры 1–9 — ввод; стрелки — выбор клетки; N — заметки; Backspace/Delete/0 — очистка; Ctrl/Cmd+Z — отмена. Клавиатурные команды не перехватываются в полях ввода и диалогах. При замене/очистке цифры логические исключения перестраиваются; отмена возвращает и доску, и кандидатов, и заметки. Ошибки/подсказки отменой не списываются.

```text

js/campaign.js         фиксированные уровни, сюжет, ранги
js/progress.js         награды, формат сохранения и валидация
```

Модули движка/кампании/прогресса доступны как browser globals и CommonJS для тестов. Runtime-зависимостей и шага сборки нет.

### Изменения решателя

Открытая пара не исключает собственные клетки (регрессия старого `pairs[b]`). Кандидаты сохраняются между шагами. Поиск действительно выполняет возврат и явно помечен как вычисленный, а не логический шаг. Победа проверяется по сетке, не по окончанию анимации. Генератор рандомизирует полное решение и использует Fisher–Yates для удаления цифр. Поиск ограничен бюджетом узлов; неоднозначные и неразрешимые позиции не считаются решёнными. Асинхронный разбор отменяется токеном при смене режима и при скрытии вкладки.

Логика: единственный кандидат, единственное место, открытые пары/тройки, скрытые пары, указующие пары/тройки, сокращение блока, X-Wing, Swordfish, XY-Wing, простое окрашивание. Пояснения — текст, не исполняемая разметка импортированных данных.

## Проверки

```sh
npm test
npm run check
```

Node.js 18+, установка пакетов не требуется. 23 теста, включая регрессию пары, сохранение кандидатов, все шесть уровней, награды, испорченные сохранения, лимит поиска и 40 детерминированных случайных сеток. В последних каждый логический шаг сверяется с единственным решением.

Дополнительная проверка интерфейса:

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser_smoke.py
# При системном Chromium: CHROMIUM=/path/to/chromium python3 tests/browser_smoke.py
```

Сценарий не обращается к сети: встраивает локальные исходники в Chromium и использует in-memory адаптер `localStorage`. Проверяет прохождение всех уровней реальным вводом, заметки/отмену, восстановление в новой странице, темы, демонстрационный режим, переключение во время анимации, импорт позиции, практику, экспорт/импорт сохранений, отказ записи и мобильную ширину 390 px. Скриншоты — `/tmp/archive81-checks` (или `SCREENSHOT_DIR`). Это не проверка реального хранилища браузера или опубликованного хостинга.

Перед публикацией на конкретном хостинге вручную: сделать ход и обновить страницу; закрыть/открыть вкладку; экспортировать и импортировать прогресс; проверить буфер обмена и сохранение на телефоне. Сам хостинг и Safari/Firefox этим сценарием не проверяются.

## Следующие главы

Расширяй `js/campaign.js`, затем обновляй последовательность и схему прогресса с миграцией. Для новых уровней проверяй единственность, логический путь и соответствие обучаемому приёму. Не удаляй существующие ID из опубликованных сохранений без миграции. Следующие главы и разновидности судоку с дополнительными правилами в версию 1.0 не входят.
